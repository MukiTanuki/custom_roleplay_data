# custom_roleplay_data

A Minecraft Java Edition 26.3 datapack that lets players change the
`minecraft:custom_model_data` value of held items for use with resource packs.

Use `/trigger CustomModelData set <value>` while holding an item. By default,
each change requires one experience level. Run
`/function custom_roleplay_data:admin` to view the configuration control. The
control suggests a `set_required_level` function call; edit its `level` value
before running it.
